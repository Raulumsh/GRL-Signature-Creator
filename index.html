How to install

Outlook desktop: File → Options → Mail → Signatures. Create new, paste the copied signature.
Outlook web: Settings → Mail → Compose and reply → Email signature.
Gmail: Settings → See all settings → General → Signature.
Apple Mail: Mail → Settings → Signatures. Uncheck "Always match my default message font" first.
Granite River Labs internal tool. Your details are saved to localStorage in your browser only, and never sent to a server.
