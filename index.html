SGS brand rules

Always:

  • Font: Arial only
  • Name in SGS Orange (R 255, G 102, B 0)
  • Plain white background
  • Essential info only — clear and professional

Never include:

  • Personal images, quotes, or icons
  • Links to social networking sites
  • Outlook V-cards, music, or video

How to install

Outlook desktop: File → Options → Mail → Signatures. Create new, paste.
Outlook web: Settings → Mail → Compose and reply → Email signature.
Gmail: Settings → See all settings → General → Signature.
Tip: Set signatures to auto-attach to every new email, reply, and forward.
Internal tool · All data stays in your browser (localStorage) and is never sent to a server.
